# Brawler Arcana Guide

**FemboyDev Field Notes 001-C** · Taiwan server · Reviewed 12 November 2026

This is the Arcana companion to the [Brawler Build Sheet](BRAWLER_BUILD.md). Skill names follow the repository's preferred English names in [Skills and Specializations](SKILLS.md). For the overall build and hotbar, return to the [repository home](README.md).

> **Short answer:** build toward four Punishment set pieces, then choose two flexible cards for better Brawler skill rolls or survival. Do not sacrifice strong skill options just to force a set.

## Arcana in Brief

| Grade | Options granted |
|---|---:|
| Common | 1 |
| Rare | 2 |
| Epic | 3 |
| Unique | 4 |

Arcana can add skill levels and stats, as well as contribute set bonuses. A skill roll is most valuable when it crosses a specialization breakpoint or improves a skill you actually use.

## PvE Set Plan

### Starting target

**Four Punishment pieces + two flexible pieces.** Use the other two slots for strong core-skill rolls, a useful defensive set, or better stats. This is a target direction, not a universal best-in-slot combination.

### How to choose between cards

1. Keep a skill roll that moves a core skill across an important specialization breakpoint.
2. Compare the complete set bonus, not just a card's name or grade.
3. If survival interrupts your rotation, keep defensive pieces instead of forcing four damage cards.
4. Re-evaluate after patches; sample data below predates the 11 November 2026 Brawler changes.

## Skill-Roll Priority

### Damage setup

1. **Ascending Blow**
2. **Exploding Fist**
3. **Rampage**
4. **Chain Fist**
5. **Flurry** or **Roundhouse**

### Offensive passives

1. **Rampage Amplification**
2. **Dominance**
3. **Impact Hit**
4. **Frontal Breakthrough**

### Tune for the problem you have

| If the problem is… | Consider… |
|---|---|
| Rage runs out and Rampage drops | Massive Rage or stronger Rage-supporting skills |
| You die or lose too much uptime | Protection / defensive pieces, Focused Block or Blood Flow Block support |
| Your core attack is below a specialization threshold | A card that adds a level to that exact skill |
| Your set is already working and key skills are at target | Compare the card's stats and remaining set bonus |

## Reported Offensive Stat Direction

These are player-reported targets, not official requirements:

| Arcana type | Common offensive target |
|---|---|
| Chalice | Time |

Compare the stat with the skill roll and set bonus. A card that has the right stat but misses a core skill breakpoint is not automatically the better choice.
