## Build Priorities

### PvE mastery targets

Treat level targets as investment goals. Gear, Arcana and Daevanion can add skill levels, so check the character's displayed level before spending more resources.

| Priority | Skills | Target / reason |
|---|---|---|
| 1 | Ascending Blow, Exploding Fist | Work toward 20; main burst skills, both benefit from Martial Arts. |
| 2 | Rampage, Chain Fist | Work toward 20; core state and frequent damage skill. |
| 3 | Flurry, Roundhouse | Get to 16, then improve toward 20 for the filler cycle. |
| 4 | Ferocity, Phantom, Pulverize | Raise as frequently used buff/setup skills. |
| Passive core | Dominance, Rampage Amplification, Impact Hit, Frontal Breakthrough | Prioritize these offensive passives; raise Massive Rage if Rage sustain is weak. |
| Utility | Focused Block, Blood Flow Block, Shoulder Tackle, Gale Strike, Ground Slam | Invest to suit encounter difficulty and survival needs. |

### Suggested spending sequence

1. Get the core attack cycle and burst skills to **level 16** where practical.
2. Raise **Ascending Blow, Exploding Fist, Rampage and Chain Fist** toward **level 20**.
3. Improve Flurry, Roundhouse, Ferocity, Phantom, Pulverize and key passives.
4. If the build loses Rampage to Rage starvation, prioritize Rage-related options. If deaths interrupt the rotation, invest in defense before squeezing out a small theoretical damage gain.

The level-20 goals are player-build recommendations, not a requirement to max one skill before touching the others. A Taiwan player sample gathered on 7 October 2026 showed high investment in Ferocity, Dominance, Rampage Amplification, Phantom, Pulverize and Impact Hit. The sample predates the 11 November patch. See [Taiwan build statistics](https://gamewith.ai/aion2/en/build-stats/tw/fighter).

### Skill growth system

- Skill Points raise mastery skills through their base levels.
- Additional skill levels can come from Daevanion, equipment and Arcana.
- Specialization choices unlock at skill-level thresholds. The general skill guide documents levels 8, 12, 16 and 20; confirm the current threshold and option text in the Taiwan client.
- Taiwan's Chapter 1 update raised Stigma skill levels to **25** and expanded equipped Stigma slots to **six**.

The Stigma cap and slot update is covered in the [Chapter 1 update report](https://www.4gamers.com.tw/news/detail/80410/nc-aion2-chapter1-land-of-sand-and-frost-update-launchd). General specialization mechanics are summarized in the [AION 2 skill system guide](https://aion2.wiki.fextralife.com/Skills).

That general system guide describes the usual breakpoints as: first specialization slot at level 8, the next choice at 12, another option at 16, and the third slot at 20. Use the Taiwan skill panel as the final authority for the current skill.

## Stigma Loadout

Taiwan build statistics show **Ferocity, Phantom and Pulverize** among the most-used Stigma skills. Start with those three, then use the remaining unlocked slots for damage or survival.

| Stigma role | Preferred skill | When to use |
|---|---|---|
| Core damage | Ferocity | Main Rage and damage-cycle support. |
| Core damage | Phantom | Common offensive setup skill. |
| Core damage | Pulverize | Common offensive setup skill. |
| Damage flex | Surging Cleave | Frequently equipped damage option in the Taiwan sample. |
| Damage flex | Discharge Energy | Frequently equipped damage option in the Taiwan sample. |
| Survival flex | Focused Block or Blood Flow Block | Choose manual block utility or recovery for the encounter. |

Level the Stigma skills you keep equipped. The October sample showed Ferocity near level 25, Phantom around 23 and Pulverize around 23 on average, but it is a pre-patch snapshot, not a universal target.

## Specialization Choices

### Changes live on 11 November 2026

| Skill | Current effect / change | Build implication |
|---|---|---|
| Flurry attack chain, specialization 4 | Ascending Blow cooldown reduction on hit was replaced with skill critical rate. | Do not select it for the removed cooldown effect. |
| Rampage | Cooldown increased to **15 seconds**. Specialization 5 now grants a brief Martial Arts effect on cast. | Start it when you can attack and prepare a burst hit. |
| Exploding Fist, specialization 5 | Adds damage against targets immune to incapacitation. | Consider it for bosses with that immunity. |
| Focused Block | Block duration is **1 second**, cooldown is **10 seconds**, and successful blocks reduce cooldown. | Keep it manual. |
| Gale Strike | Earlier patch changed one specialization to move Brawler in front of the target. | Use it as movement utility, not the old frontal-damage effect. |
| Chain Fist | August notes report PvE damage +10%; specialization 4 changed to +20% skill speed and specialization 5 to critical rate during Rampage. | Confirm the live tooltip before selecting the numbered options. |
| Rampage defense | The 14 October update added 20% PvE damage resistance while Rampage is active. | Helpful mitigation, not a reason to stand in lethal attacks. |
| Blood Flow Block | The 8 July update added a life-absorption effect. | Consider it when recovery matters more than another damage option. |

### Player-tested starting choices

The numbered selections below come from Taiwan player testing published before the latest patch. Use them as a starting point only, then verify the current tooltip.

| Skill | Tested starting choices | Current note |
|---|---|---|
| Flurry | 1 / 4 / 5 or 2 / 4 / 5 | Fourth choice is now skill critical, not Ascending Blow cooldown reduction. |
| Roundhouse | 2 / 4 / 5 | Common tested baseline. |
| Rampage | 1 / 3 / 5 | Fifth choice supports the Martial Arts burst window. |
| Exploding Fist | 1 / 2 / 5 | Fifth choice adds damage to incapacitation-immune targets. |
| Ascending Blow | 2 / 5 | Keep ready for Martial Arts. |
| Chain Fist | 3 / 4 / 5 | August update changed fourth and fifth effects; check current tooltip. |
| Typhoon Flurry | 1 / 4 / 5 or 2 / 4 / 5 | Choose damage, Rage recovery or survival. |
| Gale Strike | 3 / 4 | Movement option is useful for repositioning. |
| Spinning Kick | 2 / 4 | Player-tested boss-damage choice. |

For survival, earlier testing recommended replacing a Rage-recovery choice on Flurry or Typhoon Flurry with life absorption. Make that trade when survival is actually limiting your uptime.
